Each time a spike occurs in a node, it also applies hebbian reinforcement to all edges originating to it. The reinforcement

\Delta_{strength}(edge,t) = \alpha_h e^{-\tau_h^2(t_{source}-t_{sink})^2}

Controls the intensity in the change in strength of an edge given the the degree of spike coincidence at a given time t.

\Delta_{strength}(edge,t) = \alpha_h e^{-\tau_h^2(t_{source}-t_{sink})^2}

The amount of consecutive time a node can spend inactive (no spikes) before removal.
The amount of consecutive time an edge can spend inactive (no spikes in either source or sink node) before removal.

The number of nodes, on average, that will spawn per second. Node spawning is randomize and is governed by (javascript): 

const shouldSpawn = Math.random() ≤ rSpawnNode;

Typically, nodes should spawn much less frequently than edges.

The number of edges, on a given node, that will spawn per second. Edge spawning is randomize and is governed by (javascript): 

const shouldSpawn = Math.random() ≤ rSpawnEdge;

Typically, edges should spawn much more frequently than nodes.

In this simulation, instead of simulating reconnection, we simulate edge removal (probabalistically) follwed by new edge spawn.
